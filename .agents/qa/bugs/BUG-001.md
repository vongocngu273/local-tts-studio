## 1. Description & Summary

When invoking `ExportService.exportProjectBundle(projectId, targetDirectory, options)` on a project where segments have not yet been rendered to audio (e.g. newly created segments or pending queue items with `status: 'pending'` and `audioPath: null`), `ExportService` attempts to unconditionally compose audio by calling `audioCompositionService.composeProjectAudio(projectId)`.

Because uncompleted segments exist, `audioCompositionService.composeProjectAudio` throws:
```text
Error: Cannot compose audio: X of Y segment(s) are not ready.
```

In `src/main/services/export/export.service.ts`:
1. The call to `audioCompositionService.composeProjectAudio(projectId)` is not wrapped in error handling.
2. The service attempts audio composition even if the user only requested non-audio exports (such as `includeMarkdownManifest: true`, `includeScriptOriginal: true`, `includeIndividualSegments: true` with `includeMp3: false, includeWav: false`).
3. Furthermore, downstream properties `composition.durationMs` and `composition.segmentCount` in `project.json` and `manifest.md` generation assume `composition` is always non-null, which would cause additional `TypeError: Cannot read properties of null` exceptions if composition fails or is null.

---

## 2. Minimal Reproduction Steps

1. Create a project in `projectRepository` with 1 or more segments in `status: 'pending'`, `audioPath: null`, `durationMs: null`.
2. Do not generate or compose audio (`audioCompositionService.getLatestComposition(projectId)` returns `null`).
3. Invoke `exportService.exportProjectBundle(projectId, targetDirectory, { includeMarkdownManifest: true, includeIndividualSegments: true, includeMp3: false, includeWav: false })`.
4. Observe the unhandled rejection:
   `Error: Cannot compose audio: 1 of 1 segment(s) are not ready.`

---

## 3. Expected Result

1. `exportProjectBundle` should not crash when audio is not yet generated.
2. If `includeMp3` or `includeWav` is requested but composition cannot be completed, audio export should be safely skipped or logged with warning without failing the entire bundle.
3. If audio is not ready, `composition` may be null/undefined. The service should safely fallback:
   - Composition duration defaults to `0` (`00:00`).
   - Total segments defaults to `segments.length`.
4. `segments/` directory should only include segments that actually have audio files on disk (omits pending/non-existent audio segments). If no segments have audio, `segments/` directory is omitted.
5. `manifest.md` should be successfully generated displaying the segments' current status (e.g. `pending`), durations (`0`), and metadata.

## 6. Root Cause & Suggested Fix for `backend-specialist`

In `src/main/services/export/export.service.ts`:

1. **Guard composition attempt**: Only attempt composition if `(opts.includeMp3 || opts.includeWav)` is true, and wrap the attempt in `try...catch`:
   ```ts
   let composition = audioCompositionService.getLatestComposition(projectId);
   if ((opts.includeMp3 || opts.includeWav) && (!composition || !composition.outputMp3Path || !fs.existsSync(composition.outputMp3Path))) {
     try {
       const compResult = await audioCompositionService.composeProjectAudio(projectId);
       composition = compResult.composition;
     } catch (err) {
       logger.warn('export:bundle', 'Could not compose audio for project (segments may not be ready)', err);
     }
   }
   ```

2. **Safe access to composition**:
   - In MP3 export: `if (opts.includeMp3 && composition?.outputMp3Path && fs.existsSync(composition.outputMp3Path))`
   - In WAV export: `if (opts.includeWav && composition?.outputMp3Path && fs.existsSync(composition.outputMp3Path))`
   - In Project JSON:
     ```ts
     composition: {
       durationMs: composition?.durationMs ?? 0,
       segmentCount: composition?.segmentCount ?? segments.length
     }
     ```
   - In Markdown Manifest:
     ```ts
     const totalSeconds = Math.floor((composition?.durationMs || 0) / 1000);
     const minutes = Math.floor(totalSeconds / 60);
     const seconds = totalSeconds % 60;
     const formattedDuration = `${String(minutes).padStart(2, '0')}:${String(seconds).padStart(2, '0')}`;
     ...
     `| Total Segments | ${composition?.segmentCount ?? segments.length} |`,
     `| Composition Duration | ${formattedDuration} |`,
     ```

## 7. Regression Risk

Low. Modifying `export.service.ts` to add optional chaining and graceful error catching on composition will protect exports from aborting when audio is absent or failing, while preserving existing behavior for fully rendered projects.
