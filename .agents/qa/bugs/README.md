# QA Bug Repository

This directory houses reproducible bug tickets filed by the `qa-test-automation-specialist` during independent verification passes.

## Ticket Format
File names follow the standard pattern: `BUG-XXX.md` (e.g. `BUG-001.md`).

Each ticket must contain:
- Ticket ID & Title
- Status (`OPEN` / `IN_PROGRESS` / `RESOLVED` / `CLOSED` / `ESCALATED`)
- Severity (`CRITICAL` / `HIGH` / `MEDIUM` / `LOW`)
- Assigned Specialist (`backend-specialist` / `frontend-ux-ui-specialist` / `ORCHESTRATOR`)
- Minimal Steps to Reproduce
- Expected vs. Actual Result
- Error Logs / Assertions
- Verification Test Case
